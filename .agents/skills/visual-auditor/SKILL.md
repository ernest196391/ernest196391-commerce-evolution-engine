# Visual Auditor — Commerce Evolution Engine v0.2

Leer primero `AGENTS.md`, `SECURITY.md` y `docs/VISUAL_AUDIT.md`.

## Objetivo
Capturas públicas y señales de experiencia visual en tres pantallas, con informe JSON y CSV.

## Procedimiento
1. Confirmar autorización sobre el dominio y uso de recursos GitHub Actions.
2. Revisar y fijar un máximo de ocho URLs públicas y el dominio exacto. No seguir rutas privadas, checkout, sesiones ni parámetros secretos.
3. Ejecutar CLI o workflow **manual** según la documentación.
4. Revisar capturas reales antes de afirmar problemas visuales o estéticos.
5. Distinguir observación, verificación con fuente y recomendación.
6. Entregar por producto: screenshot, URL, ancho, errores técnicos y prioridades humanas.
7. Proponer cambios como borrador; no publicar ni modificar fotos.

## Reglas
Cero credenciales, cero datos privados, cero automatización de compras, API pagada desactivada, nunca falsificar resultados de una corrida no efectuada.
