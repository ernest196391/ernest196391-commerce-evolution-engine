# Seguridad y privacidad

## Límites v0.1
No hay credenciales, integración remota ni servidor escuchando. El analizador trata CSV como datos no confiables. Solo escribe los resultados en la carpeta elegida por quien lo ejecuta.

## Publicación
No cambiar tiendas, stock, precios ni pedidos; no activar APIs facturables ni enviar imágenes privadas a terceros. Futuras operaciones requieren autorización, privilegio mínimo, registros sin PII, pruebas y reversión.

## Reportes
Nunca publiques claves, contactos de clientes, credenciales o archivos privados. Usa ejemplos sintéticos.

## Integraciones futuras
Separar lector público, lector autenticado, creador de borradores y publicador. Ningún agente recibe acceso root ni una terminal arbitraria.
