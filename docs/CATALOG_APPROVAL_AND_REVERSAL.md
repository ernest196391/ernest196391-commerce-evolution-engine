# Approval and reversible text plans (offline)

ApprovalLedger binds the exact immutable input, supervisor result, tenant, resolved numeric WooCommerce product ID, SKU, text before/after and plan hash. Requires all HUMAN_CHECKS explicitly true; append-only local decisions, revocation invalidates future previews. Caller identity is a local operator label, **not authenticated**. Never expose this API publicly before integrating authentication and authorization. Offline preview checks current identity and exact expected text against the approved snapshot, forward or inverse. Text allowlist: name, description, short_description. No price, stock, status, orders, media uploads, image deletion or production writes. A snapshot supplied locally is not proof of a fresh WooCommerce read. No production approval has been recorded. Image publishing/rollback still needs a separate attachment-ID mapping and backup; KM-9013 and Sankey use SKU in current pilot records, cannot enter numeric-ID gate until resolved.

30 local tests passed (4 new approval tests) using synthetic snapshots and mocked supervisor. Reversal restored all three text fields in memory without altering stock or price; missing/revoked approval, concurrent edits, mismatched tenant/ID and different plan hash rejected.
